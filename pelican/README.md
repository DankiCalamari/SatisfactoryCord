# Pelican Egg

Import `egg-satisfactorycord.json` into Pelican Panel to create a SatisfactoryCord server type.

The egg runs SatisfactoryCord as the foreground process and SatisfactoryCord launches the vanilla Satisfactory Dedicated Server as its child process.

Default blocked words file path for Pelican:

```text
/home/container/satisfactorycord/config/blocked-words.txt
```
